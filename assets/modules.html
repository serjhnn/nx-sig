nX-sig module map

Columns are import depth: a module sits one column right of the deepest module it imports, so every import points left. Solid lines are import statements; dashed lines are modules loaded by name at run time (importlib): commands collects every shell/*_cmd.py, notifier loads only the channel named by config.json "notify", and process collects the TASK of every engine that has one. Those engines import process, so its dashed lines point right and don't place it. Written from the code by python scripts/gen_deps.py.

One box per type of module. An arrow goes from a type to a type its modules import; its number and width are how many imports, and a dashed arrow is one made only of modules loaded by name. Imports between modules of the same type are counted in its box. Columns are import depth, as in the modules view; tasks loading the engines points right. Click a module in the panel to see it in the modules view. Written from the code by python scripts/gen_deps.py.
